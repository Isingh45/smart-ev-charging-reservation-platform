# Smart EV Charging Reservation Platform

Cloud-based EV charging reservation platform developed for CS 623 Cloud Computing at California State University, East Bay.

## Overview

This project demonstrates a serverless cloud architecture for managing EV charging station reservations.

The platform allows users to:

- Create charging reservations
- Select charging stations
- Choose reservation time slots
- Submit reservation requests through a web interface
- Store reservation data in AWS DynamoDB

## Technology Stack

- React
- AWS API Gateway
- AWS Lambda
- Amazon DynamoDB
- JavaScript
- Python
